Encly for the desktop: third-party software
===========================================

Encly itself is licensed under the Apache License 2.0 (the LICENSE file of the installer). The desktop app also
contains the following software, which is used under its own licence. The texts and notices are in this folder.
The libraries and fonts that every Encly build contains (Kotlin, Compose Multiplatform, Okio, SQLCipher, ...) are
listed in the app under About -> Licenses.

    Builds the PDF of a note and sends it to the printer.            https://pdfbox.apache.org/
    pdfbox-LICENSE.txt, pdfbox-NOTICE.txt

ICU for Java (ICU4J) 79.1                            Unicode License v3
    Joins Arabic letters and orders mixed left-to-right and         https://icu.unicode.org/
    right-to-left text in the PDF of a note.
    icu4j-LICENSE.txt

Noto Sans Arabic                                     SIL Open Font License 1.1
    The Arabic letters in the PDF of a note (embedded in it).       https://github.com/notofonts/arabic
    NotoSansArabic-OFL.txt

Apache Commons Logging 1.4.0                         Apache License 2.0
    Used by PDFBox.                                                  https://commons.apache.org/proper/commons-logging/
    commons-logging-LICENSE.txt, commons-logging-NOTICE.txt

Java Native Access (JNA) and JNA Platform 5.19.1     Apache License 2.0 (also available under LGPL 2.1 or later)
    Calls the operating system: the secret store, the screen lock,    https://github.com/java-native-access/jna

    jna-LICENSE.txt, jna-AL2.0.txt, jna-LGPL2.1.txt

dbus-java 5.2.2 (core and the native Unix socket transport)   MIT License

SLF4J 2.0.20 (API and the no-op binding)             MIT License

    bouncycastle-LICENSE.txt

Skiko 0.150.2 (the Skia bindings under Compose Multiplatform)    Apache License 2.0

    skiko-LICENSE.txt, skiko-NOTICE.txt, skia-LICENSE.txt

JetBrains Runtime API 1.9.0, JSpecify 1.0.0          Apache License 2.0
